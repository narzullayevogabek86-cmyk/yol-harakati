# Native App Preview

This folder starts the React Native migration without touching the existing Capacitor app.

Included in phase 1:

- intro screen
- signs screen backed by `signs-static.json`
- fines preview screen
- settings UI screen

Not migrated yet:

- quiz flow
- search
- native permissions bridge wiring
- secure questions/native storage

Run locally:

```bash
cd native-app
npm install
npm start
```
